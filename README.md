# ChatApp Backend 💬

Backend for a real-time ChatApp built with **Node.js, Express.js, MongoDB, and Socket.IO**.

## 🛠️ Tech Stack

* Node.js
* Express.js
* MongoDB + Mongoose
* Socket.IO
* dotenv

## 🚀 Setup

```bash
git clone <repository-url>
cd BACKEND
npm install
```

Create a `.env` file:

```env
PORT=3000
MongoDb_URI=your_mongodb_connection_string
```

Run the server:

```bash
node server.js
```

## ✨ Features

* Real-time messaging with Socket.IO
* REST APIs with Express
* MongoDB database
* Client-server communication
